# Python Automation & Security Portfolio

Practical Python tools built on Ubuntu Linux for business process automation, data cleanup, and web security auditing.

## Featured Projects
* **Website Uptime & SSL Monitor (`site_monitor.py`)**: Checks domain availability, measures HTTP response latency, audits TLS/SSL certificate expiration dates, and exports alerts to CSV.
* **Automated Sales & CSV Cleaner (`report_cleaner.py`)**: Removes duplicate entries, standardizes text formatting, filters incomplete rows, and calculates revenue breakdowns.
* **Web Scraper to CSV (`lead_scraper.py`)**: Extracts structured product titles, cleaned pricing, and stock status from web pages into Excel-ready CSV files.
* **Cyber-Guard Security & Scanner Tools (`scanner.py`, `cyber_app.py`, `bank.py`)**: Authentication hashing, lockout protection, audit logging, and security header checks.

## Tech Stack
* **Language:** Python 3
* **Libraries:** `requests`, `BeautifulSoup4`, `csv`, `ssl`, `hashlib`, `logging`
* **Environment:** Ubuntu Linux, Git & GitHub CLI
