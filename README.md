# Python Web Scraping & Data Automation Portfolio

A collection of production-ready Python scripts for static and JavaScript-rendered web scraping, automated price monitoring, REST API extraction, and spreadsheet cleaning.

## Tech Stack
* **Python 3**
* **Scraping & Browser Automation:** `requests`, `BeautifulSoup4`, `Playwright`
* **Data Processing & Export:** `pandas`, `openpyxl`, `csv`

## Included Automation Scripts

1. **`lead_scraper.py`** — Extracts structured product/business listings, cleaned pricing, and stock status from static HTML pages into Excel-ready CSV files.
2. **`dynamic_scraper.py`** — Uses headless Chromium via `Playwright` to render JavaScript-heavy single-page applications (SPAs) and export structured records to CSV.
3. **`report_cleaner.py`** — Ingests raw `.csv` or `.xlsx` spreadsheets, strips whitespace, removes duplicates and blank rows, and exports clean datasets.
4. **`price_monitor.py`** — Tracks product prices and stock availability across multiple URLs and appends timestamped history logs to `price_history.csv`.
5. **`api_extractor.py`** — Fetches JSON payloads from REST APIs, flattens nested objects using `pandas.json_normalize`, and exports clean tabular CSV reports.
